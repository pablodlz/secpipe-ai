# ADR-0005 — Licença Apache-2.0 (público/OSS)

**Status:** Aceito (Fase 0).

## Contexto
O projeto será público e reutilizável por terceiros; é ferramenta de segurança (patentes importam).

## Decisão
Licenciar sob **Apache-2.0**: permissiva + **concessão explícita de patente** (melhor que MIT para tooling de segurança). Diferente dos bots (proprietários) — este nasce open-source de propósito.

## Consequências
- (+) Adoção ampla; proteção de patente; profissional.
- (−) Não impede uso comercial por terceiros. Aceito — é a intenção (ser a melhor opção free do mercado).
